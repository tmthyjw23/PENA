# Operator platform — 20 November 2026 WITA

## Yang tersedia

Masuk ulang memakai akun yang telah diberi hak, lalu buka /operator/ atau menu Operator platform.
Desktop: tautan di bawah sidebar. HP: buka menu akun (inisial). Operator tetap memiliki ruang surat
biasa; menu Ke ruang surat mengembalikannya ke aplikasi sekretaris.

- Ringkasan jumlah akun/organisasi serta agregat AI/ekspor 24 jam.
- Daftar akun dengan pencarian dan paginasi maksimal 25. Detail status/verifikasi/last login;
  aktif/nonaktif memerlukan alasan 8–300 karakter dan checkbox konfirmasi. Audit mencatat perubahan
  berhasil, pelaku, sasaran, sebelum/sesudah, waktu. auth_version naik dan token akun yang belum
  dipakai dibatalkan. Arsip surat, keputusan dan tanda tangan tidak diedit.
- Organisasi: pencarian metadata nama/singkatan/pemilik/jumlah anggota/surat. Tidak ada akses
  otomatis operator ke isi surat atau gambar tanda tangan dan tidak ada mutasi isi organisasi.
- Layanan: flag konfigurasi AI/email, model atau combo, keberadaan converter, hasil uji AI terakhir.
  Flag konfigurasi tidak disebut layanan berfungsi. Uji manual mengirim JSON contoh melalui AiClient,
  satu kali per menit per operator/maksimal lima per jam platform. Hasil dicatat tanpa respons mentah.
  Pengiriman email tidak dilakukan panel. Tombol AI memakai kuota provider bila pengguna menekannya.
- Log: audit operator atau metadata AI/ekspor, 25 per halaman. Tidak menampilkan prompt, output,
  validation mentah, PNG, token, password hash, origin privat atau API key. Label model dan alasan
  menolak/menyamarkan kredensial konfigurasi; view tetap escape semua teks.

## Akses dan bootstrap

Migration 006 menambah platform_operators, operator_events dan operator_checks. Tidak ada seed hak
dan nama akun admin bukan izin. Service memeriksa akun aktif, email verified dan keanggotaan operator.
Controller operator menjaga akses di constructor, termasuk permintaan ke metode inherited.
Setiap metode service yang mengembalikan data/manipulasi akun memeriksa aktor; CSRF+POST di controller.
Middleware membaca role terkini untuk navigasi. Otorisasi tidak mempercayai flag session sebagai bukti.

Status akun operator tidak dapat diubah lewat web; semua hak operator dikelola melalui console:

    php scripts/operator.php grant EMAIL 'Alasan pemberian hak'
    php scripts/operator.php revoke EMAIL 'Alasan pencabutan hak'

Gunakan terminal server pribadi dengan konfigurasi DB yang sesuai; jangan mengirim password/API key
ke chat. Console menolak akun nonaktif/nonverified serta revokasi operator aktif terakhir, mengunci
daftar role saat perubahan, menaikkan auth_version, dan mencatat audit CLI. Tidak ada endpoint web grant.
Pengguna memilih akun pembuat surat #2 (ID 4) untuk bootstrap produksi; grant sudah dilakukan.
Satu operator terdaftar setelahnya, sesi akun itu perlu login ulang. Tidak mengubah password/email.

lulus di kandidat dengan DB sementara. Test operator membuktikan semua read biasa ditolak, no-auto-role,
