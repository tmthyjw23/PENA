- Lokal: tujuh perintah Composer (`check`, `test`, `test:schema`, `test:flow`, `test:ai`, `test:workspace`, `test:exports`) lulus; validasi Composer strict dan `git diff --check` lulus. Pemeriksaan sintaks terbaru mencakup 72 berkas PHP. Tes ekspor Windows benar-benar membuat PDF. AI memakai transport palsu pada tes ini.

Direktori/berkas cache paket diperbaiki menjadi 755/644, tetap root-owned tanpa izin tulis layanan. Converter memakai direktori kerja, HOME, XDG dan profil privat per job. Uji ulang sebagai `pena` berhasil menghasilkan PDF A4 satu halaman; hasil render diperiksa, tabel dan tiga penanda tangan tidak terpotong.
- Browser lokal/publik, lebar 1440 dan 390: beranda 200, panel/teks yang diminta tidak ada, tidak ada overflow horizontal atau error JavaScript. Login dan daftar 200; dashboard anonim berakhir di login. File `.env`, storage dan SQL ditolak (403 lokal, 404 publik).
