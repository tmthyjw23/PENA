## Cara berbagi yang paling mudah

1. Kirim https://pena.egg3l.site beserta **Panduan-Pengguna-PENA.pdf** kepada teman yang ingin membuat surat.
2. Jika ingin satu lampiran, kirim **PENA-Untuk-Teman.zip**. Isinya hanya panduan dan contoh pesan, tanpa kode atau dokumentasi teknis.
3. Teman membuat akun sendiri, memverifikasi email dan menyimpan provider/API key sendiri. Tidak ada akun operator bersama atau API key untuk dibagikan.
4. Teman yang hanya menjadi pemeriksa cukup diberi tautan pemeriksaan khusus dari detail surat, melalui pesan pribadi. Tautan itu bukan undangan umum mencoba aplikasi.
5. Simpan **Dokumentasi-Teknis-PENA.pdf** untuk mempelajari proyek. Versi HTML yang disimpan pada folder dokumentasi repositori menautkan sejumlah berkas kode; PDF menampilkan path sebagai acuan. HTML/PDF dapat dibaca tanpa server aplikasi.

Sumber Markdown bisa diedit. PDF dan HTML adalah hasil ekspor edisi ini; perbarui keduanya setelah isi sumber berubah. File HTML bersifat mandiri dan tidak membutuhkan instalasi PHP/Node untuk dibaca.
