# AI pribadi PENA — 20 November 2026 WITA

## Keputusan dan penggunaan

Pengguna meminta tiap akun dapat membawa provider/API key sendiri dan memilih secara eksplisit
provider resmi **serta endpoint kustom**. Satu koneksi pribadi aktif per akun. Sejak keputusan 21 November, akun biasa wajib memilih provider dan menyimpan kunci sendiri setelah verifikasi/login. AI platform hanya tersedia bagi operator yang terdaftar eksplisit.
Buka `/preferensi/` lewat menu **Pengaturan AI**, pilih sumber, provider, ID model, lalu isi kunci dan
kata sandi akun. Konfirmasi pengiriman data/kuota. Tombol uji mengirim satu pesan contoh tanpa surat.

Preset: OpenAI, OpenRouter, Groq, Google AI Studio (Gemini). Endpoint kustom memakai OpenAI Chat Completions dengan bearer key,
`messages`, `max_tokens`, `temperature`, dan balasan `choices[0].message.content`. Preset OpenAI memakai
`max_completion_tokens` dan tidak mengirim temperatur agar tidak ditolak model reasoning. Tidak semua
model, gateway, atau API native provider didukung; Anthropic Messages belum diimplementasikan.

Endpoint kustom berupa base URL seperti `https://ai.contoh.com/v1`; PENA menambahkan `/chat/completions`.
Hanya domain publik HTTPS port 443. Tidak menerima IP literal, user/password URL, query, fragmen,
path traversal atau path terenkode. Gateway privat/localhost tidak diterima lewat pengaturan pengguna.
Konfigurasi platform yang dipercaya operator tetap boleh memakai 9router di loopback.

## Perlindungan dan batasnya

- `AiSettings` memusatkan penyimpanan dan pemilihan koneksi. Controller selalu memakai pemilik dari
  sesi, bukan `user_id` kiriman form atau pemilik organisasi. Akun harus aktif dan email terverifikasi.
  Koneksi pribadi berlaku bagi permintaan akun itu di semua ruang yang boleh diaksesnya, tidak bagi
  rekan organisasi. Belum ada kebijakan organisasi untuk mengizinkan/melarang provider per organisasi.
- AES-256-GCM, nonce acak 12 byte, tag 16 byte; associated data mengikat versi format, user, provider,
  model dan base URL. Database menyimpan ciphertext. Kunci kosong mempertahankan kunci pada provider
  dan alamat yang sama; mengganti provider/alamat wajib memasukkan kunci baru.
- Kunci tidak ditampilkan lagi, tidak masuk session, browser storage PENA, prompt, URL, log operator,
  atau pesan error provider. Form memakai POST, CSRF dan `no-store`. Kata sandi diperlukan untuk
  simpan/pilih platform/hapus; maksimal 10 percobaan per 15 menit per akun. Argumen stack trace
  dinonaktifkan dan parameter sensitif ditandai. Pantulan teks/model yang persis memuat bearer key
  disamarkan sebelum diteruskan ke pencatatan/tampilan; ini bukan jaminan terhadap provider berbahaya.
- Panel operator dan anggota organisasi tidak memiliki fungsi baca kunci. **Server tetap membuka
  kunci di memori** untuk panggilan provider; akses root/eksekusi kode yang menguasai aplikasi beserta
  kunci induk dapat membukanya. Ini bukan penyimpanan zero-knowledge atau integrasi KMS.
- `AiEndpoint` memeriksa semua hasil A/AAAA saat panggilan jaringan, menolak campuran publik–privat
  dan rentang lokal/reserved/metadata, serta memasang `CURLOPT_RESOLVE` ke IP yang lolos. Proxy dari
  environment dinonaktifkan, protokol hanya HTTPS, TLS hostname/sertifikat diverifikasi, redirect
  ditolak. Ini mencegah lookup ulang cURL mengubah tujuan setelah validasi DNS. Respons dibatasi
  ke 1 MiB agar gateway tidak mengirim balasan tanpa batas. Kebijakan konservatif
  dapat menolak jaringan khusus yang sah. Firewall egress tetap merupakan pertahanan tambahan;
  pengujian ini bukan audit penetrasi menyeluruh.
- Gateway kustom menerima key dan data permintaan. Pemilik akun harus mempercayai pengelolanya dan
  memperhatikan kebijakan retensi provider serta izin organisasi untuk mengirim isi surat ke sana.
  Gunakan kunci khusus PENA dengan batas biaya di dashboard provider. PENA belum menghitung biaya
  mata uang atau menjamin batas tagihan; kuota aplikasi tetap berlaku walaupun menggunakan BYOK.
- Tidak ada fallback diam-diam setelah koneksi pribadi gagal. Perubahan konfigurasi di antara langkah
  penyusunan menghentikan kelanjutan/tulis ulang dan meminta susun ulang. Hasil yang sudah tersusun
  dapat disimpan tanpa koneksi/kunci AI. Permintaan yang sudah berjalan tidak dapat dibatalkan dengan
  menghapus/mengubah koneksi; pengubahan melalui sesi lain juga tidak menarik kembali data terkirim.
- Uji manual dibatasi jeda satu menit dan lima percobaan per jam per akun. Status konfigurasi bukan
  bukti model berhasil membuat surat. Menyimpan pengaturan tidak memanggil provider otomatis.
- Hapus koneksi menghapus ciphertext aktif. Akun biasa kembali wajib mengatur koneksi; hanya operator kembali ke platform. Cadangan/permintaan yang
  sudah terkirim tidak langsung terhapus. Pencabutan API key harus dilakukan juga di provider.

## Kunci induk dan pemulihan

Kebutuhan runtime: ekstensi OpenSSL (ada di XAMPP PHP 8.2 dan VPS PHP 8.3). `AI_CREDENTIAL_KEY`
berisi base64 dari **32 byte acak**, atau `AI_CREDENTIAL_KEY_FILE` menunjuk file privat yang berisi
nilai base64 tersebut. Jika keduanya terisi, nilai langsung digunakan. Jangan menaruh rahasia di Git,
chat, web root, log, atau skrip dengan nilai literal. Kosongnya kedua variabel menonaktifkan penyimpanan
pribadi; AI platform tetap bekerja. Salah/hilangnya master menolak dekripsi tanpa fallback.

Produksi memakai `/srv/pena/ai-credential.key`, root:pena mode 0640, di luar direktori rilis/web.
File ini tetap dipertahankan saat rollback rilis. `.env` hanya berisi path. Simpan cadangan master
terlindungi secara terpisah dari dump database dan batasi akses keduanya. Jangan mengganti master
selama ciphertext masih ada; rotasi perlu proses dekripsi/enkripsi ulang terkontrol yang belum dibuat.
Kehilangan master mengharuskan pemilik memasukkan kuncinya lagi. Cadangan pada VPS yang sama belum
melindungi kehilangan seluruh VPS; salinan terenkripsi di tempat lain belum dijadwalkan pada tugas ini.

## Struktur MVC dan verifikasi

- Controller: `app/controller/preferensi.php`, guard seluruh route sejak constructor; POST/CSRF dan
  kata sandi untuk perubahan. Tidak menampilkan ulang input rahasia, termasuk saat gagal.
- Model/domain: `app/Service/AiSettings.php`, `AiEndpoint.php`, `AiClient.php`; tabel `user_ai_settings`
  lewat migrasi 007 dan skema instalasi. `surat::_aiClient` menyelesaikan koneksi pengguna; uji AI
  operator tetap `AiClient::fromEnv` (platform). `LetterAiService::attachToLetter` menyimpan provenance
  tanpa harus membuka kredensial saat menyimpan draf.
- View: `app/view/preferensi/ai.php`, menu desktop/ponsel, indikator sumber di Buat surat; feedback
  skeleton memakai mekanisme bersama. Form tetap dapat dipakai tanpa JS.
- Uji backend: `test:ai-settings`, `test:ai-endpoint`, `test:ai-client`; regresi schema/workspace,
  accounts/operator/flow, AI controller/clarify/personal, signatures, unit, lint dan arsitektur lulus.
  Database uji memakai identitas MariaDB yang hanya diberi hak `pena_test_*`, tanpa akses DB produksi.
- Chrome pada aplikasi/DB/storage/session uji: anonim termasuk inherited route ditolak; CSRF dan
  password salah ditolak; URL internal/tidak sah ditolak; simpan custom + consent berhasil; key tidak
  ada di HTML/input setelah redirect; akun lain termasuk operator tetap platform dan tak melihat
  model pribadi; sumber AI terbaca di form; 1440/390 tanpa overflow/JS error, screenshot diperiksa.
  Hapus dengan password lulus pada pengulangan khusus. Harness awal salah mengutip assertion setelah
  hapus sebenarnya berhasil; tidak ada perubahan guard aplikasi untuk meluluskan harness.
- Semua respons AI di uji fungsional memakai transport palsu; tidak menggunakan API key pribadi
  nyata dan tidak mengirim email. Keberhasilan kuota/model/provider milik pengguna belum dibuktikan.
- Tambahan transport nyata: fixture HTTP loopback menguji respons JSON, batas 1 MiB, serta penolakan
  redirect. Opsi return-transfer sempat menimpa callback sehingga jawaban kosong; diperbaiki dan uji
  diulang lulus. Satu permintaan HTTPS ke OpenRouter tanpa API key/data pengguna menghasilkan 401
  yang diharapkan, membuktikan DNS/TLS/pinning berjalan; ini bukan uji generasi model berbayar.

## Pembatasan akses 21 November 2026

`AiSettings` memeriksa hak operator dari database saat memilih/memakai platform; flag sesi bukan otoritas kunci. Akun tanpa baris pengaturan atau baris lama mode platform tidak mendapat client platform jika bukan operator. Pencabutan peran berlaku pada resolusi client berikutnya; permintaan yang sudah terkirim tidak dapat ditarik.

Guard akun mengarahkan pengguna biasa tanpa mode personal ke Pengaturan AI pada akses ruang kerja. Endpoint JSON AI mengembalikan 403 dengan setup_url. Login/logout, verifikasi/pemulihan akun, Bantuan dan review tamu tetap dapat diakses. Operator tetap melewati guard dan dapat memakai default platform atau koneksi pribadi.

Pengaturan yang sudah ada dipertahankan; tidak perlu memasukkan ulang kunci setiap login. Tersimpan berarti lolos validasi konfigurasi, belum membuktikan kunci, kuota atau model bekerja. Penyimpanan/login tidak memanggil provider; Uji koneksi tetap tindakan manual yang memakai kuota. Master dan ciphertext lama tetap. Detail uji: [hint dan akses AI](HINTS-AI-ACCESS-2026-11-21.md).
