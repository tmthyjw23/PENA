# Bukti MVC PENA — 20 November 2026 WITA

## Kesimpulan

PENA memakai PHP native MVC dari fondasi template, dengan lapisan service/query sebagai bagian
dari model aplikasi. Ini bukan Laravel atau penggantian framework. Pemisahan belum sepenuhnya
ketat: masih ada query baca di controller dan beberapa perhitungan presentasi di view.
Adanya folder bernama model/view/controller saja tidak cukup sebagai bukti; alurnya berikut ini.

## Batas pemisahan

- [app/controller/dashboard.php:38](D:/collage/AI/FINALE/pena/app/controller/dashboard.php:38): controller dashboard masih memiliki query catatan revisi.
  Pindahkan ke LetterQuery ketika menyentuh modul dashboard berikutnya; tidak perlu mengganti framework.
- Controller surat masih mengoordinasikan transaksi penyimpanan draf AI dan lampiran log. Dapat
  dipindah ke satu service kasus penggunaan saat modul itu diperluas.
- View melakukan format tanggal, hitungan status, dan hash pratinjau untuk formulir. Tidak ditemukan
  koneksi/query/mutasi database di view pada pemeriksaan statis yang ditambahkan.
- Service mengembalikan data dan melempar error domain; template HTML berada pada view. Model bukan
  hanya kelas dalam app/model: LetterService, ApprovalService dan LetterQuery memuat aturan/data.

## Cara memeriksa ulang

Jalankan composer test:architecture. Pemeriksaan memindai PHP dalam semua view untuk akses database,
memeriksa pewarisan Controller, dan keberadaan komponen utama. Lulusnya pemeriksaan ini membuktikan
batas yang diperiksa, bukan kesempurnaan MVC atau bebas bug. Test alur/surat/persetujuan melengkapi
bukti perilaku; semua query dan aturan tetap perlu review saat modul baru ditambahkan.

Tambahan operator: operator controller mengoordinasikan OperatorService dan Db, kemudian merender
view operator. Pemeriksaan boundary kini 10 controller/24 view dan lulus setelah implementasi ini.
